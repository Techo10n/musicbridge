# Roadmap

## Phase 1: Core MVP (in progress)

- [x] User accounts (Supabase auth)
- [x] Streaming service connections (Spotify, YouTube Music)
- [x] Library access (playlists, saved songs, followed artists)
- [x] Playlist/song sharing between users
- [x] Cross-platform playlist conversion
- [ ] Apple Music integration (deferred — see [[integrations/apple-music]])

## Phase 2: Expanded Integrations

- Additional streaming services
- Improved track matching (ISRC, fuzzy matching, duration similarity)
- Apple Music (when funded)

## Phase 3: Social Platform

- Following system
- Music feed (following + discovery)
- Post likes/comments
- Direct messaging with music

## Phase 4: Creator Ecosystem

- Verified artist profiles
- Playlist promotion
- Audience analytics
